填写跟进说明后，该项进入 **人工跟进** 分类，可按订单号检索。
这不是已恢复、退款成功、质检通过或财务闭环；不向 ERP 发布待办。

## 已退款的退货核账

模块2原逻辑会将已经退款的明细匹配订单再次报为“质检后再退款”。
现在先判断平台成功事实：未退款仍保留独立质检闸门；已退款转为只读退货核账。

拼多多独立运单：校验客户名下 TH、完整型号颜色数量、售后身份、商家应收金额、
对应 SK 退款流水、无欠货、客户应收严格为零；核验成功清除本项轮询错误，
订单保持“客户名下已收到”并显示“退款后核账已核实（非质检结论）”。
证据保存在 Git 忽略的 `.runtime/audits/module2-post-refund.sqlite3`。
不创建验货 PASS，不改变平台退款或统一资金账本，不调用 ERP 补单。
每次现有模块2轮询仍重新核验，沿用30分钟轮询，不新增定时任务或开关。
暂存待认领、非零余额、缺失流水、金额或客户不符仍保留待核账提示；
多售后共运单、个案人工锁与实收不符仍保留原保护，天猫不借用拼多多流水接口。
