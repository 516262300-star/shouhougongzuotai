## 20小时无物流提醒

- 使用官方 `/order/searchList`、`/order/orderDetail` 读取普通订单，逐包裹使用真实发货时间，不要求先有售后。按20小时修改窗口完整分页；初次沿用最近72小时修改记录回溯，之后使用原持久化游标及重叠窗口。
- 校验授权店铺、订单及包裹商品关联。分页缺失、总数改变、重复、未知状态或包裹缺失均报错，不推进失败窗口。
- 满20小时且快递100明确确认无轨迹才准备提醒；任何有效节点均不提醒。鉴权、网络、验证码、缺少顺丰逐运单电话等错误不能解释成无物流。
- 完整查询父单售后及详情，以明确成功的实际退款金额排除全额退款；部分退款继续监控。关闭或已完成订单排除，资料冲突则暂不发送。
- 复用现有原销售业务员归属、包裹合并、发布前二次核验和发送防重。结果不明只回查、不重发。已发后查到轨迹退出日常催揽收列表，但不改原ERP凭证、不声称ERP待办已撤回。
- 开启后可在“人工待办→发货20小时无物流提醒”查看；“接入能力”按实际开关、兼容发布代码和运行记录展示，不以代码存在冒充已运行。

## 模块3：未发货退款后的ERP平账

只接受当前四店中的显式白名单店铺、上线ID水位之后、同步安全且待核验的已退款仅退款订单。逐次核实：

1. 平台父订单及商品子单明确退款关闭，发货时间为0，包裹列表明确为空；售后是发货前退款且资金状态成功。没有出库物流、退货运单或物理物流证据。
2. 父单全部平台售后和工作台本地售后均唯一；仅单子单、完整数量。完整型号、颜色、数量一致，申请金额、实际退款、父单/子单实付及本地金额一致。
3. 旧ERP退款管理列表与原始执行详情一致；存在唯一原销售订单、原收款和所属客户。ERP执行退款金额必须等于平台实退。不能把优惠差额、部分退款、多个售后或其他收退款流水自动抹平。
4. 核验完整欠货及全部发货分页；旧页面无发货时须同时具备明确“当前没有单据”、完整空表及1/0分页，并回读一致。仅抖音余额表兼容已实测未闭合展示链接；其他表格截断仍阻断。
5. 缺退款单且满足条件时，先持久化资金幂等记录，再重新核实平台/ERP事实，单次调用现有 `deleteprodlist` 的 `actionid=1`。不调用抖音退款接口，不重试资金请求、不跟随资金请求重定向。
6. 只有对应唯一ERP退款流水、无欠货及零应收同时真实成立才标记闭环。HTTP成功不等于完成。请求结果不明保留UNKNOWN，只允许只读回查；既有成功流水可只读认回，不能重复补单。

没有ERP原销售记录时停止，不能伪造原单、实收单、退款单或“已平账”；复杂订单仍人工核验。

## 配置和执行

四项配置均不含密钥，默认不启用：

```dotenv
DOUYIN_SHIPMENT_REMINDER_ENABLED=false
DOUYIN_MODULE3_ENABLED=false
DOUYIN_MODULE3_SHOP_CODES=[]
DOUYIN_MODULE3_MIN_ORDER_ID=0
```

继续复用既有四店官方应用、授权token缓存、快递100和ERP专用账号，不把临时token写死。

提醒正式启用需要：兼容独立提醒版本、发布指针原有 `platforms` 中追加 `DOUYIN`、提醒开关为true、原ERP写及人工待办发布开关允许。保留PDD/TMALL/JD及京东绑定配置；不增加另一套计划任务，沿用每5分钟任务。入口 `shipment-watch-run.py` 随候选代码一起验收。

模块3启用需要：`DOUYIN_SYNC_ENABLED`、`DOUYIN_MODULE3_ENABLED`、`MODULE3_WORKER_ENABLED`、`MODULE3_ERP_REFUND_EXECUTION_ENABLED`、`ERP_WRITE_ENABLED` 均满足，配置白名单（仅 `douyin-third-party-01` 至 `04`）及明确历史水位；沿用现有后台模块3阶段，不额外启动worker。

只读预演时仍需指定店铺白名单，但不要打开写开关。CLI默认不会创建动作任务、资金流水或回写闭环：

```powershell
python -m aftersales_workbench.workflows.module3_erp_refund_cli --platform DOUYIN --limit 20 --details
```

`--apply` 才涉及真实ERP动作，必须在明确授权的店铺和历史范围内启用并复核。不要拿真实订单试探资金接口权限。普通订单提醒CLI省略 `--publish` 不对外发布，但会持久化本地监控账本，不是完全无数据库写入。

## 发布与回退

正式Worker/Web/提醒版本不是同一个源码快照，禁止将开发目录整包覆盖生产。下一步先备份各自实际发布目录、指针及配置，按职责增量组装候选，验证依赖、测试、只读预演和状态显示，再在明确执行范围内切换。Web的能力显示不得因导入ERP执行依赖而无法启动。

停用抖音提醒关闭独立开关/从提醒平台集合移除DOUYIN；停用模块3关闭抖音独立模块3开关，保留其他平台。回退源代码及配置不回滚业务数据库，不删除游标、发送账本、资金UNKNOWN或原始退款凭证。没有实际发布时不能引用本候选分支为正式运行版本。
