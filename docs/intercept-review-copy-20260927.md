# 拦截超时人工待办简化

适用范围：拦截发送前整包裹核验连续不可用、超过30分钟后生成的 `PACKAGE_NOTICE_REVIEW_REQUIRED` 人工待办。

正文只说明系统尚未发送拦截通知、发货运单和下一步操作：核实包裹内全部商品均申请全额仅退款后通知快递拦截退回，群内已通知的不要重复发送。删除同一事项中重复的超时解释、“保留收货/部分退货”等其他场景提示；主订单已经出现在原标识中，不再重复列出，其他归属及关联订单仍完整展示。

不从“仅退款申请”推断“钱已退”。此文案不能代替整包裹核验，也不表示系统已发快递群。原业务员、任务身份、远端查重标识和完整核验证据保持。

原后台下次刷新未发送待办时使用简版，新建待办同样生效。已经发送的历史正文和ERP回执保留，不为缩短文案重新发送，也不改写已尝试或结果未知的历史。网页只读预览未尝试发送的记录时使用相同模板。此次没有恢复已取消的快递群通知任务；自动拦截漏发与待办文案是分别验收的事项。

沿用原后台周期和发送开关，不增加定时任务、配置或资金操作。代码与线上候选使用相应回归验证，正式版本及结果在部署验收后补充。
