## 重启后的操作

1. 等待 Windows 更新和重启完成，在正式机登录日常运行账户，进入桌面；不能只停留在开机或登录画面。
2. 打开企业微信并确认已登录、可以看到工作群。如果要求扫码或验证，由账户使用者完成。
3. 保持接电、开盖、桌面未锁定，发送期间避免切换到浏览器或其他程序。
4. 登录触发器会启动网页和后台，守护任务每 5 分钟检查一次。打开桌面 AfterSales-Local，检查后台最近完成时间、企微通知状态和发送队列。五分钟检查周期不代表所有业务会在五分钟内处理完，实际还受同步与核验耗时影响。
5. “尚未输入、等待自动重试”可等待下一轮；如果仍不恢复，核对企微登录、桌面锁定及报错信息。“PasteStarted / SendPressed / 发送结果未确认”必须先核对群内原消息，不点击重复发送，不删除发送或包裹防重记录。正在处理中的短暂中间状态应结合活跃工作循环判断。
