# 人工待办自动发布开关与 ERP 闭环复核（2026-09-08）

## 给使用者的说明

进入“人工待办”，页面顶部新增“自动发布给业务员”开关。它统一控制模块1、模块2、模块3的 ERP 人工待办发布，不是删除待办、停止生成待办或关闭整个售后工作台。

- 关闭：继续生成和查看本地待办，后台不再领取新的发布任务；不会撤回已发送的待办，不影响售后同步、平台退款、快递通知、ERP 退货查询或平账。
- 开启：先弹出确认，明确提示待发送积压数量；确认后从后台下一个待办发布阶段按原规则处理积压及新任务。没有增加“绕过归属核对”或“强制重试失败任务”的权限。
- 发送前再次检查：登录、查重、读取表单期间关闭，尚未提交的任务退回待发送，不消耗发送重试次数；已经开始提交的任务可能完成，须在发送审计中核对，不重复发送或自动撤回。
- 页面展示“已关闭”“已开启”或“已开启但被配置阻止”，显示待发送/发送中/失败数量、最近调整时间和最近10次开关记录。状态每10秒读取，可手动刷新。保存失败/超时时不显示成功，不自动重复 PUT；先读取实际状态再决定。
- 仍要求 ERP 写入总开关及登录凭据可用。缺少条件时不能开启，关闭操作仍然允许。
- **本次上线保持关闭，没有真实发送测试。** 开启/关闭完整流程在隔离测试数据库与模拟 ERP 中验证；本机只验证保持关闭。

## 存储、兼容与安全边界

迁移 `20260908_0022` 新增 `automation_switches`、`automation_switch_events`，不改订单、任务、同步游标或历史水位，不预填启用值。

`erp_manual_todo_publish` 没有保存过网页设置时，使用原 `.env` 中 `ERP_TODO_PUBLISH_ENABLED` 作为初始状态；保存后以数据库值为准，重启、刷新页面或换浏览器不会丢失。原配置项不是数据库开关之外的第三重否决项，否则目前 `.env=false` 时网页无法真正开启。`ERP_WRITE_ENABLED` 仍为独立总闸，网页无法修改它或凭据，也不会影响其他写权限。

不编辑 `.env`，不建立新调度任务。后台每轮、每个待办领取前、ERP 提交前读取独立短事务，避免旧 `Settings` 或 MySQL 可重复读事务导致关闭后仍使用旧开关。已提交请求不可撤回；保存关闭不声称正在途的请求已取消。

API：

- `GET /api/v1/aftersales/manual-todos/publishing`：只读当前有效状态、配置阻止原因、队列数量和最近操作。
- `PUT /api/v1/aftersales/manual-todos/publishing`：仅保存本地开关和审计，不直接发布；请求包含严格布尔 `enabled`、整数 `expected_version`。版本不一致返回409，阻止多页面旧状态覆盖或超时后盲目重试。
- PUT 仅接受本机回环客户端、本机 Host、同源 Origin，以及 `X-Workbench-Action: manual-todo-publish-switch`。工作台当前没有完整用户权限系统，因此不把可触发对外发布的开关直接开放给局域网。生产使用地址为 `http://127.0.0.1:8000/` 或对应本机同源地址；第三方页面、远程访问、缺少操作标识会被拒绝。不要伪造代理头绕过校验。
- 开关表不存在或查询失败时停止尚未提交的发布，不能自动回退为开启。接口错误不包含凭据或原始数据库错误。任何人能直接控制本机/数据库仍在本系统的信任边界内，本机校验不是完整账户登录方案。
- 同时修复人工待办接口的模块筛选：前端已有模块2选项，后端现在允许 `origin=module2`，不再错误返回422。

## ERP 退货闭环复核

本次检查时，本地模块1待匹配任务42笔：35笔 `not_found`、4笔 `item_mismatch`、2笔 `receivable_open`、1笔 `staged`。这是本地待匹配任务分布，不是42笔均实时重新查询，更不代表42笔全部应转人工。

每类抽一笔只读查询 ERP，四类结果与本地记录一致：

- 未找到：客户与暂存列表未找到对应运单退货单，继续等待；不能断言包裹未到仓。
- 明细不一致：退货单存在，累计应收虽为0，仍不能用余额单独覆盖型号/颜色/数量不匹配。
- 应收未归零：一笔最新为0.04元，退货单已匹配，但不擅自抹平差额或标记闭环。
- 暂存待认领：暂存退货单仍存在，尚不能认定已归入客户销售/退货档案；本次没有认领或补单。

沿用 ERP 退货核对最短间隔1800秒、每批20笔。1800秒是单笔再次检查资格，不承诺整队列一定在30分钟内全部完成。后续重点是查明应收差额及明细不一致原因，并单独验收暂存认领；人工待办开关不会绕过这些安全条件。
