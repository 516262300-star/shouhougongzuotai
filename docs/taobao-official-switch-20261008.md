## 配置及边界

- `TAOBAO_API_URL=https://eco.taobao.com/router/rest`，`TAOBAO_REQUEST_METHOD=POST`。
- `TAOBAO_SHOPS_JSON` 保留既有 `shop_code`，避免新建重复店铺或丢失同步水位；更新真实平台卖家ID、名称、共享应用凭据和淘宝主账号 `session_key`。
- `TAOBAO_SHOP_1_REFRESH_TOKEN` 保管主账号刷新令牌。
- `TAOBAO_SHOP_1_REFUND_SESSION_KEY`、`TAOBAO_SHOP_1_REFUND_REFRESH_TOKEN` 分开保管子账号授权。现有 Settings 不消费这三个额外字段；不是启用退款或实现自动续期。

- 不调用刷新接口，不调用任何退款/审核接口。卖家身份查询只能确认授权归属，不能证明退款权限或额度；不能将天猫退款审核流程无条件用于淘宝 C 店。

## 维护入口

`scripts/configure-taobao-official.py --root <工作台运行根目录> --shop-code <现有店铺代码> --expected-seller-id <已核实卖家ID>` 默认只预检；明确加 `--apply` 才修改配置。标准输入必须是含 `session`、`refresh_token`、`refund_session`、`refund_refresh_token` 的私密JSON。不要将它们放在命令参数、文档、截图、Git或普通日志中。

脚本只向固定官方HTTPS网关发送两次卖家身份只读请求，禁用环境代理、重定向和重试。两份授权必须归属同一预期淘宝C店。只改六个淘宝配置项，保留内部店铺代码及其他配置；备份旧 `.env`，校验后原子替换，并检查并发修改。备份与结果在运行机 Git 忽略的 `.runtime/audits/taobao-official-<时间>-<随机后缀>/`。Windows文件权限限当前维护账户和SYSTEM，部署前须确认维护账户就是运行账户。

脚本不启动后台、不重启Web、不修改计划任务，不读写订单数据库，不运行同步。已有进程可能缓存旧配置；Worker下个自然启动周期加载新配置，Web须按现有安全发布流程重新加载后才可声称页面已切换。不能为刷新配置强杀资金请求或移除未知维护停止标记。

失败停止，不自动换应用、不回退中转、不消费刷新令牌。回退时仅恢复这六个配置项，保留后续其他配置、店铺内部ID、同步水位、资金账本及审计。不要整份旧 `.env` 覆盖新配置，更不要回滚数据库。原中转凭据仍包含在受限备份中，不上传Git。
