# 企微群聊载入核验与发送前恢复

## 问题与修复

2026-09-15 排查发现：打开目标群后只读取一次群标题，完整群名未匹配就进入没有恢复时间的发送前暂停，连带阻塞后续队列。当时未保存发送前截图，因此无法进一步确认是群载入、OCR 还是搜索选择造成不匹配。

现在打开群后最多等待 12 秒，要求两次连续完整群名匹配，且输入框为空、无相同历史消息，才允许输入。完整群名仍未稳定匹配时，记录明确的“尚未输入”错误及 60 秒冷却时间；冷却到期后由后续工作循环重新搜索和完整核验。实际恢复时刻受工作循环调度影响。

草稿、相同历史消息、ESC、安全验证不使用此自动恢复。已经记录 PasteStarted 或 SendPressed 的任务不得降级为可自动重发状态。发送后原有完整消息、空输入框、发送状态连续核验及同包裹防重复保护保持有效。旧版本没有冷却时间的暂停记录不会批量自动解除。
