# 企业微信前台激活失败自动重试（2026-09-10）

## 原因与修复

Windows 前台窗口竞争或激活限制会使企业微信在两秒内无法稳定取得焦点。此前这种失败发生在搜索群聊和输入消息之前，却写入永久阻塞的 `PausedBeforePaste`，后续周期统一显示“桌面发送账本存在未核验任务”。人工重新入队后再次失焦，就会再次暂停。

本次仅把主窗口激活超时分类为 `DesktopForegroundUnavailableError`。确认持久化进度仍未开始输入时，账本保留 `PausedBeforePaste`，同时记录带时区的 `retry_after`，至少等待60秒。后台在发送单实例锁内检查到期时间及数据库仍为 `PENDING` 后恢复 `Ready`，重新经过通知预览、物流和防重检查再尝试。持续失败每次重新等待，不在同一轮争抢焦点。

实际重试时间为至少60秒后的下一个通知周期，并不是固定60秒必定发送。原有批量限制、后台间隔、群白名单、水位、平台与退款开关不变，无新增环境变量或数据库迁移。

以下情况不自动重试：ESC中止、安全或登录验证、找不到或无法唯一确定主窗口、未知异常，以及 `PasteStarted` / `SendPressed` 结果不明。历史账本没有 `retry_after` 时继续按原人工核验流程处理；不能仅凭错误文字重新归类。取消或完成的输入前任务按既有规则安全作废，不发消息。

后台日志现在区分“发送前暂停”“等待自动重试”和“发送结果未确认”，显示任务号及实际原因。自动重试不能保证操作者持续切窗口时发送成功，专用且保持登录、未锁屏的桌面仍更适合执行。
