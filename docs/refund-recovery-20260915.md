# 无轨迹跨天复查与拼多多退款回查修复

## 问题与行为

已成功发送拦截通知的仅退款订单，在快递100连续无轨迹后进入本地人工核对。旧逻辑只重新检查当天创建的此类订单，跨天后会遗漏，导致后来出现有效轨迹也无法恢复物流退款判断。

启用现有双接口无轨迹策略时，取消上述建单日期限制。只恢复系统原始“连续无轨迹”异常、最新平台待商家处理、UNKNOWN、无历史实物流转或退回记录、且有当前运单和快递公司成功通知的订单。带有客诉或人工暂停说明的记录不接管。按下次检查时间排序；持续无轨迹仍保留人工核对并安排30分钟后复查，有有效轨迹后才按现有规则重新判断并撤销过时的无轨迹说明。

“当天发货、双接口明确无轨迹、09:00–21:00与配置工作时段交集”等风险退款限制不变。跨天恢复查询不等于允许跨天空轨迹退款；发送通知也不代表实际拦截或仓库入库成功。退款执行仍检查最新平台申请、金额、商品、当前运单、同包裹订单以及永久资金幂等账本。

另外，拼多多退款写请求发生传输异常或返回内容无法明确确认成功时，同一次执行立即只读查询最新退款详情和订单。只有身份、金额、SKU与原批准一致且平台明确退款成功，才确认原资金账本并继续工作流；仍待处理、信息变化或回查失败时继续保留UNKNOWN，由已有只读核验流程处理。绝不再次发送该资金请求，也不把未知接口响应直接判成成功。
