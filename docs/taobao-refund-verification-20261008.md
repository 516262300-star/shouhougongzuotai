# 淘宝退款实测与自动模块边界（2026-10-08）

## 已核实的结果

北京时间14:54，一笔用户明确授权的淘宝退款由官方接口单次提交并回查成功。主查询授权与退款子账号均实时核对为同一淘宝C店；提交前核对订单、退款单、SKU、数量、金额、最新版本及既有任务/资金账本。没有调用天猫审核接口，没有中转、代理、重定向、自动重试或刷新令牌。

用户已确认子账号退款额度20,000元并开启免短信，本次使用 `ignore_code=true`；该额度是用户提供的账户设置，不是本次查询确认的每日或单笔额度口径。个案金额小于该额度，不能以此推断所有金额、全部售后状态或未来授权均可操作。

官方方法 `taobao.rp.refunds.agree` 使用淘宝三段参数 `refund_id|amount_fen|refund_version`，不附加天猫退款阶段。响应同时确认顶层成功及对应唯一退款单的逐条成功；随后只读核对退款详情和目标子单均为 `SUCCESS`，金额、店铺与商品匹配，永久资金账本记录为 `CONFIRMED`。

## 本次例外与证据保留

用户明确说明尚未收到退货，并授权此单提前退款。仅该个案允许跳过等待实收；没有建立虚构的实收分配、仓库验货记录，也没有登记ERP退款单、认领退货或平账完成。

外部请求前已提交 `money_operations` 中标准 `TAOBAO/shop/refund/PLATFORM_REFUND` 唯一键。响应不明只允许回查，不可删除账本后重做；已成功操作不得再次请求。个案脚本、原始授权范围、请求参数（无凭据）及回查证据仅保存在Git忽略的 `.runtime/audits/`。文档和远端不包含订单、退款编号、客户资料或凭据。
