## 重启后的操作

1. 等待 Windows 更新和重启完成，在正式机登录日常运行账户，进入桌面；不能只停留在开机或登录画面。
2. 打开企业微信并确认已登录、可以看到工作群。如果要求扫码或验证，由账户使用者完成。
3. 保持接电、开盖、桌面未锁定，发送期间避免切换到浏览器或其他程序。
4. 登录触发器会启动网页和后台，守护任务每 5 分钟检查一次。打开桌面 AfterSales-Local，检查后台最近完成时间、企微通知状态和发送队列。五分钟检查周期不代表所有业务会在五分钟内处理完，实际还受同步与核验耗时影响。
5. “尚未输入、等待自动重试”可等待下一轮；如果仍不恢复，核对企微登录、桌面锁定及报错信息。“PasteStarted / SendPressed / 发送结果未确认”必须先核对群内原消息，不点击重复发送，不删除发送或包裹防重记录。正在处理中的短暂中间状态应结合活跃工作循环判断。

## 今后的维护安排

Windows 更新重启应安排在有人值守的维护时间。先等待当前发送及退款请求完成，核对已校验备份，再重启，随后立即完成 Windows 与企微登录并验收后台恢复。不通过强制结束进程或关闭电源中断运行。

当前没有配置 Windows 自动登录，也没有全天候重启后自动完成企微认证的能力。因此本部署的“24 小时开机”不等于“任意重启后无人工恢复”。若要升级为重启后完全无人值守，须另行评估专用账户登录、设备物理访问保护、企微认证以及未登录时的告警方式，不能仅凭后台自启动任务宣称已实现。不要通过长期关闭安全更新来代替维护安排。

维护核查证据包括系统重启事件、桌面登录事件、`.runtime/module1-autostart.log`、`.runtime/module1-autostart-status.json`、`.runtime/module1-worker.log`、发送台账及消息回执。守护 healthy 仅表明所检查的服务/进程正常，不等于企微账号已登录或每条消息均已成功。
