## 恢复与回退约束

正常重启使用既有入口，必须保留版本指针：

```powershell
.\scripts\module1-worker.ps1 -Action Status
.\scripts\module1-worker.ps1 -Action Stop
.\scripts\module1-worker.ps1 -Action Start
.\scripts\module1-autostart.ps1 -Action StartWatch
```

不得删除版本配置使启动器回到开发目录，不得清空两张账本或重置历史任务来绕过阻断。旧代码不读取新账本，发生故障时先停止守护并安全停后台、冻结外部写入，保留账本做只读核验；不能直接恢复旧指针继续自动运行。备份恢复也不能覆盖升级后已产生的资金事实。
