## 复现命令

先准备独立MySQL实例，使用新的数据目录、仅本机监听、非生产端口及测试凭据。不要使用生产实例、生产数据目录或生产连接配置。运行者通过本地环境设置以下三个变量，不把密码放入命令行、截图或提交文件：

- `AFTERSALES_MYSQL_TEST_URL`：仅独立实例的SQLAlchemy连接字符串。
- `AFTERSALES_MYSQL_TEST_UUID`：独立实例的`@@server_uuid`。
- `AFTERSALES_MYSQL_TEST_DATADIR`：独立实例的`@@datadir`，路径包含`mysql-audit-`。
- 可选`AFTERSALES_MYSQL_TEST_REPORT`：本地结果JSON路径。

```powershell
$env:PYTHONPATH = (Resolve-Path .runtime/releases/safety-20260911/src).Path
.\.venv\Scripts\python.exe -m pytest integration_tests/test_mysql_safety.py -v --tb=short
.\.venv\Scripts\python.exe -m ruff check integration_tests/test_mysql_safety.py
```

每次执行自动创建新的合成测试数据库，保留结果便于检查。实际数据库进程重启是本轮额外执行的检查，没有冒充pytest自动完成进程重启。本地实例身份、初始化/启动/重启脚本、日志、测试XML、只读生产核对和重启结果保留在Git忽略的`.runtime/audits/mysql-safety-20260911/`。独立实例已安全停止，数据保留；不要使用递归删除清理不明数据目录。
